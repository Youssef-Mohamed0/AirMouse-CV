# 🖐️ AirMouse-CV - OpenCV & MediaPipe Hand Controller

A fast, smooth, and lightweight Python application that turns your webcam into an interactive touchless mouse. Control cursor movement, clicks, and page scrolling using simple and intuitive hand gestures.

---

## 🛠️ Prerequisites & Dependencies

The project relies on the following Python libraries:

- **`opencv-python` (`cv2`)**: Used for capturing video feed from the webcam and rendering real-time visuals/UI overlays.
- **`mediapipe`**: Google's framework used for high-fidelity 2D/3D hand landmark tracking and finger detection.
- **`pyautogui`**: Used to send programmatic GUI events (moving mouse cursor, left clicks, and scroll actions).
- **`math`**: Built-in Python module used for geometric distance and coordinate calculations.
- **`time`**: Built-in Python module used for timing control and frame delays.
